# Zodaic — Professional Web Development Portfolio

A modern, responsive portfolio and services website built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- **Home** — Hero section, stats, featured projects, testimonials, and CTA
- **About** — Background, skills with animated progress bars, values
- **Services** — Six service offerings with process workflow
- **Portfolio** — Filterable project gallery with hover effects
- **Blog** — Articles, featured post, newsletter subscription
- **Contact** — Contact form with mailto integration, social links
- **Admin** — Secure login page for portfolio management
- **SEO** — Meta tags, Open Graph, Twitter Cards on every page
- **Responsive** — Mobile-first design with smooth animations (Framer Motion)

## Tech Stack

- [Next.js 14](https://nextjs.org/) (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [React Icons](https://react-icons.github.io/react-icons/)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deploy on [Vercel](https://vercel.com) — connect the repo and it deploys automatically.
